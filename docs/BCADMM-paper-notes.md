# BC-ADMM —— 让 ADMM 解非凸约束（带环约束图）

> **BC-ADMM: A Parallel Decoupled Non-convex Constrained Optimizer for Robot Applications**
> Zherong Pan, Kui Wu @ Lightspeed Studios
> arXiv 2025（机器人/仿真通用框架）

---

## 一句话总结

**把"非凸非光滑约束"重写成"双凸约束"，引入辅助变量（比如分离平面），让 ADMM 在带环约束图上也能收敛。300 个机器人导航 30 秒搞定，Newton 要 70 秒。**

---

## 故事的起点

### 机器人/仿真里的硬约束

很多场景都涉及"硬约束 + 非凸 + 非光滑"：
- 多智能体不碰撞
- 软体不能反转（inversion-free）
- 应变限制（strain limit，弹簧不能被压扁到长度 0）
- 关节/接触不穿模

为啥棘手？

### 痛点 1：通用求解器靠不住

通用约束优化器（SNOPT、IPOPT）依赖**约束的梯度非零**这个假设。

但很多约束 **梯度在违反时反而消失**！

经典例子（论文图 2）：

```
机器人位置 x₁，要避开三角形障碍 CH(x₂, x₃, x₄)：

约束：inf_{x∈CH} |x₁ - x| ≥ r

x₁ 在三角形外面：              x₁ 在三角形里面（穿模）：
       ●  x₁                            ●  x₁
      / 梯度有定义                       三角形内部
     /  (单位向量)                       梯度消失为 0！
    ▲   三角形                          ▲   三角形
```

通用优化器一旦掉进可行域里面，**梯度消失，恢复不出来**——卡死。

### 痛点 2：可行内点法 → 步长太小

替代方案是**可行内点法**（IPC、log barrier 都属于这一类）：在可行域里加个发散的 barrier，把解关在里面。

问题：
- 全局步长被**最严苛的那一个约束**限制
- 上千个约束里只要有一个差点违反，整个步长就被拉到很小
- 收敛慢

### 痛点 3：ADMM 想解决这个，但是有限制

ADMM 的卖点是**子问题解耦并行**：
- 把全局优化拆成一堆小问题
- 每个小问题取自己的大步长
- 整体效率高

**但是**：经典 ADMM 的收敛分析要求**约束图无环**。

机器人应用里**全是带环约束图**：

```
3 个机器人两两不碰撞 → 约束图是个三角形 → 有环

  机器人 A ─── 不碰撞 ─── 机器人 B
       \                      /
        不碰撞          不碰撞
              \      /
            机器人 C
```

经典 ADMM 在这种问题上**没有收敛保证**，可能根本不收敛。

---

## 核心想法：双凸 (biconvex) Relaxation

### 关键技巧：引入"分离变量"

把每个非凸约束**拆成两个凸的子问题**，多引入一个辅助变量 z。

**经典例子：两个机器人不碰撞**（论文图 4）：

```
原约束：|x_i - x_j| ≥ 2r        ← 关于 x 非凸

引入分离平面 z = (n, d)：

  x_i ●---|---● x_j
          |
          | n（法向量），d（平面偏移）
          |
   分离平面 nᵀp + d = 0

新约束：
  nᵀ x_i + d ≥ r       ← 关于 x_i 凸（固定 n,d 时）
  nᵀ x_j + d ≤ -r      ← 关于 x_j 凸（固定 n,d 时）
  |n| = 1               ← 关于 n,d 是个凸投影问题
```

**Bi-convex（双凸）的含义**：
- 固定 z 时，关于 x 凸 ✓
- 固定 x 时，关于 z 凸 ✓
- 但**关于 (x, z) 联合不凸** ✗

## BC-ADMM 算法

### 优化形式

原问题：

```
min_x  f(x) + g~(Ax)
       ↑      ↑
       目标    非凸非光滑约束
```

引入 slack variable y：

```
min_{x,y,z}  f(x) + g(y, z)   s.t.  Ax = y, z ∈ Z
```

其中 g(y, z) 关于 y 和 z 各自凸。

### 增广拉格朗日函数

```
L(x, y, z, λ) = f(x) + g(y, z) + (β/2)|Ax - y|² + λᵀ(Ax - y)
```

### 迭代更新（4 个变量）

```
x ← argmin L(x, y_k, z_k, λ_k)              # 全局变量更新（解线性系统）
y ← argmin L(x_{k+1}, y, z_k, λ_k)          # 一致性变量（小问题，并行）
z ← argmin_{z ∈ Z} L(x_{k+1}, y_{k+1}, z, λ_k)  # 分离变量（小凸问题，并行）
λ ← λ + ρ (Ax_{k+1} - y_{k+1})              # 拉格朗日乘子
```

**关键性质**：
- y 子问题：可以**按约束逐个分解并行**（一个 pair 的不碰撞约束就是一个小问题）
- z 子问题：每个分离平面独立优化（并行）
- 完全跳出"被最严苛约束限制全局步长"的问题

### 理论保证

主定理：在合适的参数 ρ_x, ρ_y, β 下，BC-ADMM 收敛到 ε-stationary 解，**oracle complexity O(ε⁻²)**。

这跟最一般的非凸优化一阶法同阶，对一个能并行的算法来说已经很好。

## 实践细节

### 实际算法（Algorithm 1）

理论参数 ρ_x, ρ_y, β 没法构造性给出 → 实际算法用**自适应增加**策略：

1. **Lazy update of z**：z 不每次都更新，等 x 更新足够大才更
2. **Anytime feasible**：始终保留"最近的可行解" (x_best, z_best)，发现新冲突时回滚
3. **Constraint detector**：用一个外部检测器（碰撞检测器）只把"近距离的"约束加进 g（ADMM 还能处理动态约束集）
4. **失败回退**：发现不收敛时把 ρ_y 扩大 2×、β 扩大 2.1×，重新跑

### 几个应用场景的双凸重写

| 应用 | 关键非凸约束 | 双凸重写 |
|---|---|---|
| **多机器人不碰撞** | 距离 ≥ 2r | 引入分离平面 (n, d) |
| **质量弹簧 + 应变限制** | 弹簧长度 ≤ l_max | 引入方向 z ∈ S²（单位向量） |
| **ARAP + Neo-Hookean 防反转** | det(F) > 0 | 引入额外内点 y₀ + d+1 个分离平面 |

ARAP 的 z 子问题恰好是 polar decomposition——**有闭式解**，几乎免费。

## 性能

### 多机器人导航：300 个机器人换位

```
配置：
- 300 个机器人在圆周上，目标在对面
- 中间有个障碍
- 必须穿越拥堵中心
```

| 方法 | 收敛时间 |
|---|---|
| **BC-ADMM** | **~30 秒** |
| Newton's Method | ~70 秒 |
| Gradient Descent | 150 秒还没收敛 |

为啥赢 Newton？
- Newton 单步快但**每步要解大稀疏线性系统**
- BC-ADMM 子问题完全并行，单步**爆炸快**
- 总迭代数虽多，但单步省太多了

## 给草履虫的直觉

> **多人不打架** 是个非凸约束（约束图带环 → 经典 ADMM 没救）。
>
> BC-ADMM 让你**在每对人之间立一块隔板**，让"隔板朝向"做新变量 z。
>
> 这样每个人**只需要看见自己周围的几块隔板**，不需要看见所有人——子问题瞬间能并行解。
>
> 隔板自己也得调整（z 子问题），但每块隔板独立调，也能并行。
>
> 整套机制让"非凸非光滑"通过引入辅助变量变成"双向凸"，收敛性回来了，并行性也回来了。

## 跟其他论文的对比

### vs IPC（log barrier 类）

- IPC 也保证可行性
- 但 IPC 是**全局步长** → 慢
- BC-ADMM 是**子问题各自步长** → 并行又快
- 不过 IPC 在网格仿真里更成熟，BC-ADMM 主要面向机器人/导航

### vs SQP / interior point（IPOPT 等）

- 通用求解器假设约束梯度非零 → 在非光滑约束上挂
- BC-ADMM 用双凸 relaxation 绕开这个问题

### 适用条件

要求每个非凸约束有**双凸 relaxation**——不是所有问题都行：
- 碰撞、应变、防反转：✓（论文都给了）
- 任意黑盒约束：✗（需要用户/研究者找到 relaxation）

这是 BC-ADMM 的限制：**不通用**，但对它能套上的问题很强。

## 给我自己的 takeaway

1. **"双凸 relaxation 的范式"** 比这篇本身的算法更值钱。很多看起来"非凸非光滑"的约束，引入一个辅助变量后立刻变成两边各自凸——这个套路可以反复用。

2. **环约束图打破了 ADMM 收敛分析**——这个我以前没意识到。ADMM 在图形学的成功（投影动力学等）很多其实是**约束图无环**的特殊情况。

3. **可行性与效率的平衡**：BC-ADMM 始终保留 x_best 的策略，让算法既能 anytime 终止，又有最坏情况保证。这种工程化思路值得学。

4. **对游戏/Unity 物理的启发**：布料碰撞、头发自相交避免，可能可以套这个范式。Position-Based Dynamics 本质就是"对每个约束独立投影"，BC-ADMM 提供了带收敛保证的版本。
